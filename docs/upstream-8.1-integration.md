## 验收边界

上游文档记录的是上游构建结果。此分支的 macOS SDK 源码和打包规则已接入，需另外构建并验证双 Mac 执行文件。Windows 和 Linux 使用 App 官方入口和完整公开片源兜底。已公开的 1.0.7 安装包及更新说明对应原冻结提交。

本机验证通过前端生产构建、574 项桌面单元测试、105 项界面检查、101 项 Android 测试、25 项服务端测试、26 项下载管理检查和 132 项下载安全检查。两组仅访问本地回环地址的网络安全检查在测试进程内关闭 Node 环境代理后通过。

真实媒体集成回归 65/66。唯一失败在随机样本的红果取源阶段，未得到可用视频。Apple 芯片 SDK 已构建并通过 Mach-O 架构及临时签名核验。执行文件启动时本机受限进程无法初始化 PyInstaller 信号量，未进入取源。使用同一份源码和依赖在隔离缓存里复核随机选中的《做兄弟，在心中》第 10 集时遇到连接错误。Intel SDK、本项目最终安装包及静音实播仍待验证。
