## 1.0.6 更新内容

- 登录红果账号后，可在桌面查看和管理云端收藏、分集点赞和预约，也可将选中的本机收藏移到账号。
- 「收藏与上新」会随窗口宽度调整，支持卡片和列表。登录时云端收藏始终显示，本机收藏有记录时显示。未登录时显示本机收藏和空列表提示。
- 「我的预约」可切换已上线和待上线。红果提供的具体预约日期和时间即使已过也会保留显示。
- 播放器显示红果提供的系列剧，可切换已上线的剧集，并在登录后预约待上线的续作。

**Android手机APK／Android TV版：** 请前往 [N3urda/hongguoTV](https://github.com/N3urda/hongguoTV) 下载。该项目独立维护；版本、兼容性与测试状态以该项目发布页为准，不计入本项目的四平台附件或验收。
