## 1.0.7 更新内容

- 桌面端「观看记录」的红果剧集使用官方系列剧列表，显示各季的实际剧名及「待上线」状态。可继续观看已有记录的剧集，或打开其他已上线的季。
- 暂无系列剧信息时仅显示提示。网络或其他查询错误时可重新查找。

**Android手机APK／Android TV版：** 请前往 [N3urda/hongguoTV](https://github.com/N3urda/hongguoTV) 下载。该项目独立维护；版本、兼容性与测试状态以该项目发布页为准，不计入本项目的四平台附件或验收。

## 更新方式

- Mac 和 Windows 安装版可在应用内检查更新。
- Windows 便携版和 Linux AppImage 可从本页下载新版。
- Windows EXE 未签名。Windows 真实下载验收在 GitHub 虚拟机完成，非实体 Windows 电脑。
