## 1.0.11 更新内容

- 同步上游 8.3 与 8.4 播放取源与稳定性改进：新增「自动获取播放源」签名热更新策略包、`openhongguo` 社区源、设置页「取源优先级」自定义排序与 V8 空响应熔断。
- 修复 `openhongguo` 传输层未限制压缩编码导致的 `unsupported content encoding` 问题，并在 macOS 双架构与 Windows 发行包中内置 `hongguo-sdk-playback` 1080P 取源组件。
- 全面优化加解密与运行性能：新增原生 AES-128-CTR 解密与可复用零拷贝 Worker 池，优化主进程并发流控、前端渲染节流与分块构建。
- 补齐英文界面漏译并修复设置页长按钮溢出，精简历史冗余文档。

> **Android手机APK／Android TV版：** 请前往 [N3urda/hongguoTV](https://github.com/N3urda/hongguoTV) 下载。该项目独立维护。

- Windows 便携版和 Linux AppImage 可从本页下载新版。
