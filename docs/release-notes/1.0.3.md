## 1.0.3 更新内容

- 优化应用内更新。Mac 和 Windows 安装版自动下载新版，在播放和任务空闲时安装并重启。
- 播放视频时暂停自动更新，暂停或结束播放后继续。可在设置中关闭自动更新。

**Android手机APK／Android TV版：** 请前往 [N3urda/hongguoTV](https://github.com/N3urda/hongguoTV) 下载。该项目独立维护；版本、兼容性与测试状态以该项目发布页为准，不计入本项目的四平台附件或验收。

## 更新方式

- Mac 1.0.2 和 Windows 安装版可在应用内检查更新。更早的 Mac 版请从本页下载安装。
- Windows 便携版和 Linux AppImage 可从本页下载新版。
