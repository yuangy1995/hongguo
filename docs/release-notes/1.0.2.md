## 1.0.2 更新内容

- 调整发现、搜索、播放器、观看记录、下载管理和设置的桌面布局，让常用操作更容易找到。
- 观看记录支持调整卡片大小，并可在页面内同步账号记录。
- 常用设置在修改后自动保存，开启看完自动删除时会先提示确认。
- 横屏播放器的投屏入口移到顶部。关闭视频上的弹层时，可保持原有播放状态。
- Mac 支持在应用内下载适合当前电脑的新版安装包。下载完成后可打开安装包，并确认替换应用。

**Android手机APK／Android TV版：** 请前往 [N3urda/hongguoTV](https://github.com/N3urda/hongguoTV) 下载。该项目独立维护；版本、兼容性与测试状态以该项目发布页为准，不计入本项目的四平台附件或验收。

## 更新方式

- Mac 1.0.0 和 1.0.1 请先从本页下载对应芯片的 DMG 并安装一次。Mac 安装包使用临时签名。
- Windows 安装版可在应用内更新，EXE 未签名。Windows 便携版和 Linux AppImage 可从本页下载新版。
