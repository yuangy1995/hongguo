## 1.0.0 首发

- 雾白桌面界面，重新排布发现、搜索、播放器、观看记录、下载和设置。
- 手机与电脑同步观看进度，观看记录支持卡片与列表。
- 从侧栏扫码登录。选集、清晰度和换季都能在播放时操作。
- 在应用内检查本项目的更新。

**Android手机APK／Android TV版：** 请前往 [N3urda/hongguoTV](https://github.com/N3urda/hongguoTV) 下载。该项目独立维护；版本、兼容性与测试状态以该项目发布页为准，不计入本项目的四平台附件或验收。

## 安装

- Apple 芯片 Mac 和 Intel Mac 请选对应的 DMG。Mac 使用临时签名，可在应用内检查更新，从发布页下载新版。
- Windows x64 可选安装版或便携版。安装版可在应用内安装后续更新。Windows 下载、播放和安装迁移在 GitHub Windows 虚拟机完成验证，EXE 未签名。
- Linux x64 使用 AppImage。
- 已经安装过误发版本的用户，请从本页手动下载并安装 1.0.0。
